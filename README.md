# Data Structures and Algorithms with TypeScript

A collection of **Data Structures and Algorithms (DSA)** implementations using TypeScript, focused on improving problem-solving skills, understanding algorithmic complexity, and writing efficient, maintainable code.

## Algorithms

### Sorting Algorithms

| Algorithm | Time Complexity (Average) | Space Complexity | Status |
|---|---|---|---|
| Bubble Sort | O(n²) | O(1) | ✅ Completed |
| Selection Sort | O(n²) | O(1) | ✅ Completed |
| Insertion Sort | O(n²) | O(1) | ✅ Completed |
| Merge Sort | O(n log n) | O(n) | ⬜ Planned |
| Quick Sort | O(n log n) | O(log n)* | ✅ Completed |
| Counting Sort | O(n + k) | O(n + k) | ⬜ Planned |
| Radix Sort | O(d(n + k)) | O(n + k) | ⬜ Planned |

### Search Algorithms

| Algorithm | Time Complexity | Status |
|---|---|---|
| Linear Search | O(n) | ⬜ Planned |
| Binary Search | O(log n) | ⬜ Planned |

\* Quick Sort's space complexity depends on recursion depth and pivot selection. Counting Sort and Radix Sort complexities depend on the input range and digit representation.

## Goals

- Implement fundamental sorting and searching algorithms.
- Understand time and space complexity using Big O notation.
- Practice writing clean, readable, and reusable TypeScript code.
- Compare algorithm performance and trade-offs.
- Strengthen problem-solving skills and algorithmic thinking.

## Technologies

- **Language:** TypeScript
- **Runtime:** Node.js
- **Version Control:** Git and GitHub

## Learning Approach

Each implementation serves as a practical exercise to explore how an algorithm works, analyze its computational complexity, and understand when it may be useful.

This repository is a work in progress and will grow as more algorithms are implemented.
